## TVING Wath History Plus

# 목적
- 프로그램단위 시청이력이 티비에서 25일, 25개 제약이 있어 해결하려고 함
- 90일 제한으로 노출하는 시청내역의 경우 에피소드 단위로 표현해 주고, 프로그램명을 제공해주지 않는 것을 해결

# 해결방법
- 90일 내역을 제공해주는 시청내역을 제공하는 api를 사용해서 기간을 90일로 늘림.
- 프로그램단위 (추후 버전은 시리즈 단위)로 그룹핑을 하여 노출하여 에피소드 단위로 노출하는 점을 해결함.
- 보여주지 않았던 프로그램명 추가로 노출하도록 함.

# 사용방법
- 크롬 확장으로 해결해서, 로그인 권한 정보 저장없이 바로 사용됨.
- www.tving.com/my 페이지에 접속하면 'more+' 버튼이 노출됨.
- 'more+' 버튼을 클릭하면 새로운 목록을 노출하고 스크롤로 페이징 처리됨.
